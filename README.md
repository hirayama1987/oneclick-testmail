# ワンクリック捨てアド

会員登録用の使い捨てメールアドレスをワンクリックで生成し、クリップボードにコピーする Chrome 拡張機能です。

## 仕組み

いわゆる「捨てアド」ではなく、`+タグ` エイリアス機能を利用します（Gmail をはじめ、多くのメールサービスが対応しています）。

- `you@example.com` を登録すると、`you+20260915143205@example.com` のように、生成した時刻（`yyyymmddhhmmss`）をタグにしたアドレスを生成します。
- `+`以降のタグはメールサーバー側で無視されるため、生成したアドレス宛のメールはすべて元の受信箱に届きます（確認メールもちゃんと受け取れます）。
- 外部サービスやサーバーには一切通信しません。生成とコピーはすべてローカルで完結します。

## インストール方法（開発者モード）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ（`oneclick-testmail`）を選択する
5. ツールバーにアイコンが表示されるので、ピン留めしておくと便利です

## 使い方

1. 初回はツールバーのアイコンをクリックし、ベースにする自分のメールアドレスを登録
2. 以降はアイコンをクリックするたびに、その時刻をタグにした新しい捨てアドが生成され、自動でクリップボードにコピーされる
3. そのまま会員登録フォームに貼り付け
4. 履歴からいつでも過去に生成したアドレスを再コピー可能

## 多言語対応

`chrome.i18n` API で日本語・英語に対応しています。表示言語は Chrome 本体の言語設定（`chrome://settings/languages`）に従い、自動で切り替わります。

## ファイル構成

- `manifest.json` — Manifest V3 定義
- `popup.html` / `popup.css` / `popup.js` — ポップアップ UI とロジック
- `_locales/ja` / `_locales/en` — 多言語対応メッセージ
- `icons/` — ツールバー用アイコン
