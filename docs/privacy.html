プライバシーポリシー

最終更新日: 2026年9月15日

「ワンクリック捨てアド」（以下「本拡張機能」）は、会員登録用の使い捨てメールアドレスを ワンクリックで生成し、クリップボードにコピーする Chrome 拡張機能です。 本ポリシーは、本拡張機能が扱う情報について説明します。

収集する情報

  • ユーザーが設定画面で入力する、ご自身のメールアドレス（エイリアス生成のベースとして使用）
  • 本拡張機能が生成したメールアドレスの履歴と生成日時（直近20件まで）

これら以外の情報（閲覧履歴、個人を特定する追加情報、位置情報など）は一切収集しません。

情報の保存方法

入力されたメールアドレスおよび履歴は、Chrome の chrome.storage API を用いて、お使いの Chrome プロファイル内にのみ保存されます。 開発者を含む第三者が運営するサーバーへ送信されることはありません。 メールアドレスは chrome.storage.sync に保存されるため、 同じ Google アカウントでログインした他の Chrome 端末間で同期される場合がありますが、 これは Google Chrome 自体の同期機能によるものであり、本拡張機能の開発者がアクセスすることはできません。

第三者への提供

本拡張機能は外部サーバーへの通信を一切行わず、収集した情報を第三者と共有・販売することもありません。

権限について

本拡張機能が要求する権限は storage のみです。 これは上記のメールアドレスおよび履歴をローカルに保存するために使用されます。

データの削除

拡張機能のポップアップ内「クリア」ボタンで履歴を削除できます。 すべてのデータは、拡張機能をアンインストールすると同時に削除されます。

Privacy Policy

Last updated: September 15, 2026

"One-Click Burner Email" (the "Extension") generates a disposable sign-up email address and copies it to your clipboard in one click. This policy explains what information the Extension handles.

Information We Collect

  • The email address you enter as the base address for generating aliases
  • A history of addresses the Extension has generated, with timestamps (last 20 entries)

No other information — such as browsing history, additional personal identifiers, or location data — is collected.

How Information Is Stored

Your base email address and history are stored only within your Chrome profile using the chrome.storage API. Nothing is sent to any server operated by the developer or any third party. The base email address is stored using chrome.storage.sync, so it may sync across Chrome instances signed into the same Google account — this is a feature of Chrome itself, and the developer has no access to this data.

Third-Party Sharing

The Extension does not communicate with any external server and does not share or sell collected information to third parties.

Permissions

The Extension requests only the storage permission, which is used to save the email address and history described above, locally.

Data Deletion

You can clear the history at any time using the "Clear" button in the popup. All data is removed when you uninstall the Extension.
